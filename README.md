# Komentář k zákonu č. 92/1991 Sb., o podmínkách převodu majetku státu na jiné osoby

Otevřený komentář k zákonu o podmínkách převodu majetku státu na jiné osoby — § po §: doslovné znění, výklad, kazuistika, protiargumenty a praktický závěr; privatizační projekty, rozhodnutí o privatizaci, užití privatizovaného majetku a převod majetku s použitím investičních kupónů.

Konsolidované znění: dokument e-Sbírky `SB-1991-00092_2019-01-01`.
